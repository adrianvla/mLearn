# Japanese supplemental source

`enrichment-v1.json.gz` is generated by
`python3 tools/prepare-japanese-enrichment.py --reference <root-of-app-source>`.
The input hashes, reference revision, attribution and output hash are in
`../enrichment-pin.json`. Normal package builds use this frozen source offline.

Pitch data: Uros Ozvatic / Kanjium, distributed as Kanjium Pitch Accents by
toasted-nutbread, revision `pitch1`, under CC-BY-SA-4.0. Source:
https://github.com/mifunetoshiro/kanjium ; license:
https://creativecommons.org/licenses/by-sa/4.0/ .
The source is normalized and indexed for mLearn. Distinct pronunciation variants
and their source tags are preserved, rather than overwritten by reading.

Vocabulary levels come from the explicitly authorized mLearn reference's
`languages/ja.freq.json`, pinned to revision
`1788f9c74dc73dd884b687ec80d9550c3ebf6c6b`. This file does not declare a separate
upstream attribution. Do not invent one or describe this list as an official JLPT
syllabus. Labels apply to listed written-form/reading pairs.

JMdict and Sudachi retain their existing notices and source pins. This supplement
changes neither JMdict `ent_seq` target identities nor learner evidence.
